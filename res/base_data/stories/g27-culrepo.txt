As a faculty member, I want to access and search collections in the repository so that I can obtain research materials and find my own work.
As a faculty member, I want to upload my scholarly work and associated data so that I receive attribution and can share it with others.
As a faculty member, I want to assign licenses (CC-By/CC0) to my submissions so that reuse rights are clear.
As a faculty member, I want to maintain versioning of documents and datasets so that only the most current version is used.
As a faculty member, I want to control the order and branding of items in my collections so that my work is presented appropriately.
As a student, I want to locate faculty and their research on specific topics so that I can choose advisors, courses, and internships.
As a researcher, I want to search, browse, and discover items across collections so that I can efficiently access relevant content.
As a researcher, I want to receive notifications when new items are published or downloaded so that I can track usage and stay updated.
As a researcher, I want to view descriptive metadata and related items so that I can properly cite and understand resources.
As a patron, I want to subscribe to report/dataset notifications and download historical versions so that I have timely and comprehensive information.
As a patron, I want to browse by author, subject, or related content so that I can discover additional resources.
As a library staff member, I want to upload and batch upload items with metadata so that authors’ work is efficiently added to the repository.
As a library staff member, I want to create collections, including custom metadata fields, so that digital content is organized and accessible.
As a library staff member, I want to assign items to multiple collections and embargo items when required so that access policies are followed.
As a library staff member, I want to preserve both content and metadata robustly so that long-term access is maintained.
As an administrator, I want to track faculty contributions, usage statistics, and analytics so that repository performance and impact can be assessed.
As an administrator, I want to manage user accounts, roles, and permissions so that access is controlled appropriately.
As a repository support team member, I want to rename, move, or alias items/collections so that collection owner requests are fulfilled.
As an asset manager, I want redundant storage, monitoring, and restoration mechanisms so that digital assets are protected and recoverable.
As an asset manager, I want to evaluate the intellectual value of assets and ensure long-term funding so that repository sustainability is supported.
As a data curator, I want to upload new versions of items while keeping old versions accessible so that historical records are preserved.
As an Extension Administrator, I want to share project resources with other faculty and educators across NYS so that materials can be reused effectively.
As a library discovery operator, I want to harvest and expose repository metadata via OAI so that Cornell publications are discoverable externally.
As a faculty member, I want to link files to publications and ORCID/ResearcherID so that attribution is clear and unambiguous.
As a patron, I want to report issues and contact system support so that problems can be resolved efficiently.
